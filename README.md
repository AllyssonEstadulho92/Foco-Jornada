# Foco & Jornada

Aplicação de produtividade pessoal e profissional para acompanhar jornada, pausas, foco, atividades e pequenos gastos num único lugar.

## Funcionalidades

- Entrada e saída da jornada com duração baseada em timestamps
- Pausa de ecrã e descanso configuráveis
- Pomodoro/Foco com pausa e retoma
- Atividades com início, pausa, retoma e conclusão
- Registo de café e cálculo de gasto em cêntimos
- Timeline e histórico
- Tema claro, escuro ou automático
- Backup e importação JSON
- Diagnóstico de integridade dos dados
- Persistência local no browser
- PWA e funcionamento offline após a primeira visita
- Interface responsiva para iPhone, Android, tablet e computador

## Repositório oficial

## Publicação no GitHub Pages

A aplicação é estática e não precisa de Node, npm ou build.

Configuração recomendada: `Settings → Pages → Deploy from a branch → main → /(root)`.
